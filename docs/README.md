| 文件 | 對象 | 內容 |

| [使用指南](USER_GUIDE.md) | 玩家、測試人員 | 安裝、操作、設定及疑難排解 |

## 文件維護原則

- 功能、資料模型或建置需求改變時，應同步更新相關文件。
- 文件使用繁體中文；程式識別名稱與命令保留原文。
- 所有命令預設在專案根目錄執行。
- 架構文件描述目前實作，不將尚未完成的功能寫成既有能力。
