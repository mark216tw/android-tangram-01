# 使用指南

## 安裝需求

- Android 8.0（API 26）以上
- 約 30 MB 可用空間（實際大小依建置版本而異）
- 遊戲可完全離線使用

## 首頁

首頁提供四項功能：

- **開始遊戲**：進入關卡選擇。
- **遊戲說明**：查看移動、旋轉、翻面、吸附、提示與自訂關卡方式。
- **設定**：調整顯示模式、難度、拼板顏色、音效及內建關卡顯示方式。
- **結束遊戲**：將應用程式移至背景，不會強制終止程序。

## 遊戲流程

1. 點選「開始遊戲」。
2. 從已解鎖的動物關卡中選擇一關。
3. 依上方淡色剪影，將下方七塊彩色拼片移到正確位置。
4. 全部拼片吸附後完成關卡，系統會保存最佳時間並解鎖下一關。

完成資訊會顯示在遊戲畫面下方，仍可查看完整拼圖並分享完成圖案。

## 拼片操作

### 選取與移動

- 點一下彩色拼片即可選取。
- 按住拼片拖曳可移動位置。
- 選取的拼片會移至最上層並顯示醒目外框。
- 點擊空白區可取消選取。

### 旋轉

- 選取拼片後，使用底部的向左或向右按鈕。
- 每次旋轉 45 度。
- 正方形具有 90 度旋轉對稱；平行四邊形具有 180 度旋轉對稱。

### 翻面

- 只有平行四邊形可翻面。
- 選取平行四邊形後，底部翻面按鈕才會啟用。

### 吸附

- 拼片位置、方向及翻面狀態接近目標時會自動吸附並鎖定。
- 兩個大三角形可互換目標，兩個小三角形亦可互換。
- 在自訂關卡編輯器中，拼片也支援邊對邊、雙邊同時及頂點對頂點吸附。
- 成功吸附時會播放提示音；可在設定中關閉。

## 遊戲工具

- **提示**：短暫標示一塊未完成拼片及其相容目標。
- **重置**：將本關恢復到初始狀態並重新計時。
- **離開**：回到前一頁；未完成的本局狀態不會保存。
- **分享圖案**：完成關卡後，將完成圖案與關卡名稱、完成時間分享到其他應用程式。

## 自訂關卡

### 建立與編輯

1. 在關卡選擇頁點選「建立」。
2. 拖曳七片拼板排列目標圖案；兩指拖曳可移動整個圖案。
3. 使用旋轉、翻面與吸附功能調整拼板。
4. 使用「自動置中」將整體圖案同時對齊過關範圍的水平與垂直中心。
5. 點選「關卡預覽」可切換初級輪廓或高級外圍剪影預覽。
6. 點選「儲存」並輸入關卡名稱。

編輯區會顯示過關範圍與中心參考線。關卡預覽會依圖案實際上下左右範圍裁切，並保留少量安全邊距。

### 匯入與匯出

- 「匯出」會將所有自訂關卡保存為 JSON 檔案。
- 「匯入」可加入其他裝置或使用者提供的 JSON 關卡。
- 若匯入的編號與現有關卡衝突，系統會自動重新分配自訂關卡編號。

### 自訂關卡顯示

- 設定中的「隱藏內建拼圖」開啟後，關卡清單只顯示自訂關卡。
- 自訂關卡編號使用負數，例如 `-1`、`-2`；編輯關卡不會改變原有編號。

## 設定

### 顯示模式

- **系統**：依 Android 系統目前的淺色或深色模式顯示，預設選項。
- **淺色**：固定使用米白紙藝配色。
- **深色**：固定使用深色墨紙配色。

### 音效

- 預設開啟。
- 關閉後，拼片吸附不會播放提示音。
- 設定會保存在裝置上，重新啟動後仍會保留。

### 拼板顏色

可選擇經典、高彩、柔和、海洋、夕照或單色配色，設定會套用至遊戲與關卡編輯器。

### 內建拼圖

- 預設顯示內建關卡。
- 開啟「隱藏內建拼圖」後，關卡選擇頁只顯示自訂關卡；內建關卡資料與進度不會被刪除。

## 進度保存

下列資料保存在裝置本機：

- 顯示模式
- 音效開關
- 已解鎖的最高關卡
- 各關卡最佳完成時間
- 難度、拼板顏色與內建關卡顯示設定
- 自訂關卡資料

移除應用程式或清除應用程式資料會刪除上述紀錄。

## 疑難排解

### 拼片無法吸附

- 確認拼片中心已靠近剪影中心。
- 使用旋轉按鈕校正方向。
- 平行四邊形可能需要翻面。
- 若兩塊三角形尺寸相同，可交換嘗試。

### 聽不到音效

- 確認設定中的「音效」已開啟。
- 確認裝置媒體音量不是靜音。

### 畫面被系統導覽列遮住

目前介面已支援手勢導航與傳統三鍵導航。若仍發生問題，請回報裝置型號、Android 版本及畫面截圖。
